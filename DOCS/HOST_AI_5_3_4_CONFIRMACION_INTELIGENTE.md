# Host AI 5.3.4 — Confirmación Inteligente de Acciones

Clasifica las acciones del flujo entre seguras, pendientes de confirmación y críticas.

## Confirma antes de modificar

- Crear eventos.
- Asociar menús.
- Crear pedidos.
- Cualquier cambio real de datos.

## Respuestas aceptadas

- Afirmativas: `S`, `sí`, `ok`, `vale`, `adelante`, `hazlo`.
- Negativas: `N`, `no`, `cancelar`.
- Selección: `seleccionar`, `por partes`, `solo algunas`.
