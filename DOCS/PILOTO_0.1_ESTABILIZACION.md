# PILOTO-0.1 — Estabilización de la línea base

## Instalación

1. Haz una copia de seguridad del proyecto completo.
2. Copia el contenido del ZIP encima de Host AI 6.0.
3. Ejecuta `python main.py`.
4. Selecciona `9. Certificar PILOTO-0.1`.

## Nuevo arranque

- `1. Modo Piloto privado`: operativa diaria simplificada.
- `2. Modo Desarrollo`: conserva consola completa, conversación y herramientas técnicas.
- `8. Auditoría de arranque`: valida estructura, configuración, catálogos e imports.
- `9. Certificar PILOTO-0.1`: genera certificado JSON/TXT en `DATOS/certificaciones/piloto01/`.

## Garantías

- No se eliminan carpetas ni versiones históricas.
- No se migran datos.
- La certificación compara huellas SHA-256 de artículos, recetas y menús.
- El modo Piloto reutiliza los motores actuales; no duplica lógica de negocio.
