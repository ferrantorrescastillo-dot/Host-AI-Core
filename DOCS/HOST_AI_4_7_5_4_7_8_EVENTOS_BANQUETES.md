# HOST AI 4.7.5 - 4.7.8 | Eventos y banquetes inteligentes

## 4.7.5 Personal del evento
Calcula equipo necesario por tipo de evento, personas, complejidad y tipo de servicio.

## 4.7.6 Material del evento
Calcula material de sala, cocina, transporte y formatos especiales como paellas o brasa.

## 4.7.7 Cronograma completo
Genera una planificación del evento desde compras, producción, carga, montaje, servicio y recogida.

## 4.7.8 Informe final
Calcula ingresos, costes, beneficio, margen, coste por persona y recomendaciones.

## Pruebas
```powershell
python -m TESTS.test_475_personal_evento
python -m TESTS.test_476_material_evento
python -m TESTS.test_477_cronograma_evento
python -m TESTS.test_478_informe_final_evento
```

También se pueden ejecutar como archivo si la raíz del proyecto está bien en el path.
