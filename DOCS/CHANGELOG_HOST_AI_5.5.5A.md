# Changelog — HOST AI 5.5.5A

Estado: **MODELO CANÓNICO CERRADO**

La versión 5.5.5A establece una capa interna común para ingredientes, recetas, escandallos y menús. Incluye repositorio JSON atómico, validación, búsqueda, serialización e integración segura con eventos, producción, stock y propuestas de compra.

La siguiente fase, 5.5.5B, será el importador Excel flexible que convertirá hojas externas al modelo canónico sin convertir Excel en la base operativa de Host AI.
