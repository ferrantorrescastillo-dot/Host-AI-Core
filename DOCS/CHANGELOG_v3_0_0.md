# Host AI 3.0.0 - App Base Ejecutable

## Objetivo

Convertir Host AI en un programa ejecutable desde `main.py`.

## Añade

- `main.py`
- `APP/consola.py`
- `demo_host_ai_3.py`
- `TESTS/test_app_base_ejecutable.py`

## Menú principal

- Hablar con Host AI
- Eventos
- Stock
- Compras
- Escandallos
- Costes
- Producción real
- Estado del sistema

## Cómo usar

```powershell
cd "C:\Proyecto Host IA 2.0\Host IA 2.0"
python main.py
```

## Cómo probar

```powershell
python TESTS\test_app_base_ejecutable.py
```

Resultado esperado:

```text
TEST OK - Host AI 3.0.0 App Base Ejecutable
```
