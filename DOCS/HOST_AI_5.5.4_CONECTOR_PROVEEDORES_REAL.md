# HOST AI 5.5.4 — Conector real de proveedores

## Objetivo
Responder quién suministra un artículo usando las relaciones reales existentes y sus precios registrados.

## Fuentes reutilizadas
- `DATOS/db/articulos.json`
- `DATOS/db/stock_inicial.json`
- `DATOS/db/proveedores.json`
- `DATOS/db/precios.json`

## Comandos seguros
- `¿Quién vende arroz bomba?`
- `¿Qué proveedores venden arroz bomba?`
- `Proveedor de harina fuerza`

## Seguridad
Solo lectura. No crea proveedores, no cambia precios y no genera pedidos.
