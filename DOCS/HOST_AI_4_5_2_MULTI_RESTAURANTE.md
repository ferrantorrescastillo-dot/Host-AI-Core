# HOST AI 4.5.2 - Gestión Multi Restaurante

## Objetivo

Permitir que Host AI pueda gestionar varios restaurantes, hoteles o caterings sin mezclar datos.

## Incluye

- Crear restaurante.
- Listar restaurantes.
- Seleccionar restaurante activo.
- Consultar restaurante activo.
- Crear estructura separada en `Restaurantes/<slug>/`.

## Uso

```powershell
python APP/multi_restaurante_452.py
```

## Test

```powershell
python TESTS/test_452_multi_restaurante.py
```
