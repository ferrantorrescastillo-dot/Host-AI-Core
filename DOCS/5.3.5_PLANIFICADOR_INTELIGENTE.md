# Host AI 5.3.5 — Planificador Inteligente de Ejecución

Convierte un flujo operativo generado por 5.3.1 en un plan ordenado y explicado.

## Qué hace

- Ordena los pasos según dependencias reales de cocina.
- Comprueba bloqueos entre evento, menú, producción, stock, compras y costes.
- Explica por qué cada paso va en ese lugar.
- No modifica datos reales.

## Uso

```powershell
python -m TESTS.test_535_planificador_inteligente
python -m APP.planificador_inteligente_535
```
