# HOST AI 3.0.8.1 - Analizador de Lenguaje Natural

Convierte frases de cocina, compras, stock, producción y escandallos en una petición estructurada para Host AI.

## Incluye

- Normalización de texto.
- Detección de intención.
- Extracción de entidades: artículos, fechas, cantidades y proveedores.
- Selección de pipeline y acción sugerida.
- Control de confianza y aclaraciones.
- Exportación JSON.
