# HOST AI 3.0.8.2 - Motor Conversacional

Gestiona conversación, contexto operativo y respuestas naturales sin delegar la lógica de negocio a un LLM.

## Incluye

- Historial conversacional.
- Contexto entre turnos.
- Respuesta natural basada en intención y entidades.
- Limpieza y exportación de conversación.
- Preparado para selector de motores y automatización posterior.
