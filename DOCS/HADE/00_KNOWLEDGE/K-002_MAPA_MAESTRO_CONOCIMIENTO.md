# K-002 — MAPA MAESTRO DEL CONOCIMIENTO

## Objetivo
Definir una única fuente de verdad para el conocimiento de Host AI.

## Principio
El código implementa.
HADE piensa.
La documentación técnica explica.
Los documentos históricos conservan la evolución.

## Clasificación oficial

### 1. HADE (Autoridad funcional)
Contendrá exclusivamente:
- Filosofía
- Modelo mental
- Reglas
- Árboles de decisión
- Lógica de negocio
- Forma de pensar del sistema

### 2. Arquitectura
Mantiene:
- MASTER_PLAN
- AGENTS
- Arquitectura
- Componentes
- Roadmap

Estos documentos NO desaparecen. Se convierten en referencias técnicas.

### 3. Implementación
Código, motores, servicios, modelos y tests.

### 4. Históricos
Versiones antiguas, auditorías y certificaciones.

## Destino de los principales documentos

- MASTER_PLAN -> Arquitectura oficial
- AGENTS -> Reglas para desarrollo
- DEVKIT -> Referencia funcional
- ROC -> Diseño técnico
- Auditorías -> Historial
- Certificaciones -> Evidencia
- Árboles de decisiones -> HADE
- Conversaciones relevantes -> HADE (solo el conocimiento, no el texto)

## Regla de oro
Nunca duplicar conocimiento.
Cada idea tendrá un único documento oficial.

## Flujo oficial del proyecto

Experiencia real
 -> Actualización de HADE
 -> Arquitectura
 -> Sprint
 -> Codex
 -> Validación
 -> Aprendizaje
 -> Actualización de HADE

## Resultado esperado
- Una única fuente de verdad.
- Ninguna contradicción entre documentos.
- Sprints derivados de HADE.
