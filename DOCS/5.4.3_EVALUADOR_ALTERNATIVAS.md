# Host AI 5.4.3 - Evaluador Inteligente de Alternativas

## Objetivo

Cuando aparece un problema, Host AI no da una sola respuesta. Compara opciones como un segundo jefe de cocina:

- comprar al proveedor habitual
- buscar proveedor alternativo
- ajustar producción
- pedir refuerzo
- cambiar orden de tareas
- modificar menú solo como último recurso

## Seguridad

No aplica cambios reales. Solo recomienda y marca lo que requiere confirmación.
