# Host AI 5.3.6 — Priorizador Inteligente de Tareas

Clasifica las tareas de un plan operativo en prioridad alta, media y baja.

## Criterio

- Alta: tareas que bloquean servicio, stock, compras o modificaciones críticas.
- Media: producción, recursos y planning.
- Baja: informes o cálculos que no bloquean la operativa inmediata.

## Uso

```powershell
python -m TESTS.test_536_priorizador_tareas
python -m APP.priorizador_tareas_536
```
