# Arquitectura técnica I1.3.4.1.4

El motor se ejecuta entre la preimportación semántica y el clasificador gastronómico.

## Responsabilidad

Agrupar fragmentos excesivamente atomizados en unidades culinarias explicables. No busca, crea ni vincula entidades.

## Reglas

1. El conocimiento catalogado prevalece.
2. Solo se interpreta cuando existen al menos dos fragmentos no catalogados y no hay núcleo catalogado.
3. Toda salida conserva rol, confianza y evidencia.
4. Los conceptos siguen pendientes hasta ser vinculados o revisados por el usuario.
5. No se escriben menús, recetas, artículos ni aprendizajes automáticamente.
