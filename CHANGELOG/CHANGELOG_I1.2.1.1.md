# I1.2.1.1 — Integración del catálogo de artículos

- I1.2 reutiliza el mismo cargador de catálogo que Stock.
- Lee primero la base local y usa el JSON de artículos como respaldo.
- Muestra cuántos artículos se han cargado y el origen del catálogo.
- Bloquea la importación si el catálogo está vacío.
- La vista previa informa si el motor de vinculación está activo.
