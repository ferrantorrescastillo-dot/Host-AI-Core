# HOST AI 6.0.4 — UX1 Mejoras de usabilidad

## Cambios

- Enter o `0` cancelan de forma limpia la selección de artículos, necesidades y pedidos.
- Los mensajes de selección indican el rango válido y permiten volver a intentar.
- Cuando una búsqueda devuelve una sola receta, se selecciona automáticamente.
- Las preguntas de sí/no no interpretan textos como `patata` como respuesta negativa: repreguntan.
- La creación de escandallos informa cuando no se ha añadido ningún ingrediente.
- La búsqueda de artículos vacía no muestra artículos aleatorios.
- La simulación de escandallos valida primero si se eligió `1` o `2`; no solicita más datos con una opción inválida.
- Mensajes de cancelación más claros y consistentes.
